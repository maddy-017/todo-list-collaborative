# To-Do List in C

A simple to-do list program made in C.

## Features
- Add a task
- View all tasks
- Delete a task

## How to Run
1. Download the file
2. Open terminal
3. Run: gcc todo_list.c -o todo_list
4. Run: ./todo_list
